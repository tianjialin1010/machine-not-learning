4.3 环境约束下的实操命令（今天就能跑）

# 1. pip 永久换国内源（国际源全断，必做）
pip3 config set global.index-url https://mirrors.aliyun.com/pypi/simple/
pip3 config set global.trusted-host mirrors.aliyun.com

# 2. 建虚拟环境（Ubuntu 24.04 系统 Python 受管控）
python3 -m venv ~/venv && source ~/venv/bin/activate

# 3. 核心依赖（全部国内源可达）
pip install --break-system-packages langgraph gradio fastapi uvicorn \
    chromadb sentence-transformers requests

# 4. 交互体验优化：对话类前端用 8B 模型（40+ tok/s），重任务才上 27B
ollama pull modelscope.cn/unsloth/Qwen3-8B-GGUF   # 模型走 modelscope，国内秒下

# 5. 服务启动必须绑 0.0.0.0（实测验证过，绑 127.0.0.1 公网 502）
gradio app.py --server_name 0.0.0.0 --server_port 8888
两个型号策略：Demo 交互链路用 Qwen3-8B（响应快，评委视频里不冷场），报告生成/复杂诊断用 27B（质量高），两者切换本身就是「模型优化技术深度」的论据。微调在 8B 上做，快且稳。
